# 4:3 Game Mods

A collection of 4:3 mods for games, designed for handhelds and other 4:3 displays. Each game has its own documentation and release.

## Available mods

- [The Legend of Zelda: Skyward Sword HD](games/skyward-sword-hd/README.md) — game version 1.0.1, tested on Retroid Pocket Nova.

## Disclaimer

These are unofficial fan-made modifications. This project is not affiliated with or endorsed by the games’ publishers or developers. Game titles and assets belong to their respective owners.
