# The Legend of Zelda: Skyward Sword HD — 4:3 Mod

A fan-made 4:3 display mod for Skyward Sword HD, intended for handheld devices with 4:3 screens.

## Compatibility

- **Game version:** 1.0.1
- **Mod version:** 1.0.0 (based on the alpha6 build)
- **Tested device:** Retroid Pocket Nova
- **Emulator:** Eden on Android

This build has had limited testing. Some interface elements or screens may still display incorrectly. Please report issues with a screenshot and the game and emulator versions.

## Download

Download the Skyward Sword HD ZIP from [Releases](https://github.com/tskon-kz/4x3-game-mods/releases).

## Installation in Eden

1. Download and extract the ZIP.
2. Open the game’s mod directory in Eden.
3. Copy the extracted mod folder containing `exefs` and `romfs` into the mod directory.
4. Enable the mod in the game’s mod settings and launch the game.
5. Set the emulator’s aspect ratio to 4:3 if needed.

Use a legally obtained copy of the game. This unofficial fan project is not affiliated with or endorsed by Nintendo.
